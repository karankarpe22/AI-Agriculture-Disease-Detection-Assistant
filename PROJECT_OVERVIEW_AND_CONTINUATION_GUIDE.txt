1. PROJECT AT A GLANCE
================================================================================
- Project Title: AI Agriculture Assistant (कृषी सहाय्यक - Krishi Sahayyak)
- Core Mission: Provide smallholder Indian farmers with evidence-grounded,
  real-time crop disease diagnosis, microclimatic weather risk alerts, and
  expert agronomic advisory in regional languages (Marathi & English).
- Live Deployments:
  * Frontend: https://krishi-sahayyak.vercel.app (Hosted on Vercel Global Edge CDN)
  * Backend:  https://krishi-sahayyak.onrender.com (FastAPI on Render Cloud Linux)
- Key Metrics:
  * Supported Crops: Tomato, Potato, Bell Pepper (3 major horticultural crops)
  * Disease Classes: 13 distinct classes (10 diseases + 3 healthy baselines)
  * Total Dataset: 20,113 curated PlantVillage images (70% train / 15% val / 15% test)
  * Test Accuracy: 81.89% (Macro Precision: 86.99%, Weighted F1: 81.39%)
  * Inference Speed: ~21.58 ms per image on CPU
  * Model Weight Size: 16.29 MB (MobileNetV3-Large, ideal for edge/mobile)
  * RAG Index: 62 verified research chunks from ICAR-IIHR, CPRI, TNAU in FAISS
  * LLM Guidance: Google Gemini 2.5 Flash via official google-genai SDK
  * Audio Support: gTTS & browser Web Speech API for Marathi & English voice playback

3. COMPLETE SYSTEM ARCHITECTURE & END-TO-END DATA FLOW
================================================================================
The application follows a strictly grounded, multi-tier pipeline:

[Farmer / User Browser]
       │
       ▼ (1) Upload Leaf Photo OR Ask Agricultural Question
[Vercel Frontend (Vanilla JS + Glassmorphic UI)]
       │
       ▼ (2) HTTP POST Multipart / JSON (Locked CORS to Render)
[FastAPI Backend Server (Render Linux Container)]
       │
       ├─► (3) Defensive Image Quality Check (PIL + NumPy)
       │       - File size (<10MB), extension (.jpg, .png, .webp)
       │       - Resolution bounds (100x100 to 6000x6000)
       │       - Extreme darkness (<18) or wash-out/overexposure (>245)
       │       - Contrast verification (std deviation >= 12)
       │       - Blurriness detection (Laplacian variance < 15 triggers warning)
       │       - Foliage green/brown HSV color check (rejects non-leaf uploads)
       │
       ├─► (4) Deep Learning Inference (MobileNetV3-Large in PyTorch)
       │       - Preprocessing: Resize(256), CenterCrop(224), ImageNet Normalization
       │       - Forward pass produces raw logits -> Softmax probabilities
       │       - Identifies top class, confidence %, and top-3 alternate candidate classes
       │       - Optional Grad-CAM Heatmap generation (target layer features[16])
       │
       ├─► (5) Real-Time Weather & Microclimate Risk Engine
       │       - Geocodes user city (e.g., Pune, Nashik, Solapur)
       │       - Primary: OpenWeatherMap API; Auto-fallback: Open-Meteo Live API
       │       - Retrieves Temperature, Relative Humidity, Wind Speed, Precipitation
       │       - Rule-based microclimate scoring:
       │         * High humidity (>80%) + mild temp (15-22°C) -> Late Blight fungal surge
       │         * High temp (>30°C) + dry conditions -> Spider Mite pest outbreak
       │
       ├─► (6) Evidence Retrieval via FAISS RAG Knowledge Base
       │       - Semantic search using sentence-transformers/all-MiniLM-L6-v2 (384-dim)
       │       - Vector store: FAISS (FlatIP / cosine similarity)
       │       - Retrieves top-3 verified agronomic chunks from ICAR & TNAU
       │         (Chemical fungicides, organic bio-agents, preventive crop hygiene)
       │
       ├─► (7) Generative AI Synthesis via Google Gemini 2.5 Flash
       │       - System prompt strictly grounds advice on RAG evidence + weather risk
       │       - Disclaims direct clinical diagnosis; instructs farmer on field checks
       │       - Generates structured response in requested language (Marathi/English):
       │         * Summary & Symptoms Explanation
       │         * Immediate Treatment & Chemical/Organic Sprays
       │         * Long-Term Field Prevention & Crop Rotation
       │         * Safety Precautions & Withholding Periods
       │         * Specific answer to farmer's customized question
       │
       ├─► (8) Audio & Text-to-Speech Engine
       │       - Server: gTTS / edge-tts audio synthesis cached as MP3/Base64
       │       - Client fallback: Web Speech API synthesis for zero latency
       │
       ▼ (9) JSON Response returned to browser
[Vercel Frontend]
       │
       ▼ Renders diagnosis badge, confidence meter, Grad-CAM toggle, weather card,
         structured bilingual guidance cards, audio player, and follow-up Q&A thread.

6. MACHINE LEARNING MODEL & TRAINING DETAILS
================================================================================
- Backbone: MobileNetV3-Large (chosen over ResNet50/DenseNet for its tiny footprint: 16.3MB,
  depthwise separable convolutions, hard-swish activations, and fast CPU inference on modest cloud servers).
- Pretrained Base: ImageNet-1K (MobileNet_V3_Large_Weights.DEFAULT).
- Two-Stage Transfer Learning Strategy:
  * Stage 1 (Head Training): Backbone weights frozen (requires_grad = False).
    Trained custom linear head for 3 epochs with AdamW (lr=1e-3). Reached ~74% validation accuracy.
  * Stage 2 (Fine-Tuning): Unfroze the top high-level convolutional block (features[13:]).
    Trained with a lower learning rate (1e-4) with Cosine Annealing learning rate schedule for 2 epochs.
    Prevented catastrophic forgetting while tuning deep feature representations to agricultural leaf veins,
    chlorosis halos, concentric rings, and necrotic spots.
- Final Evaluation Results:
  * Validation Accuracy: 83.54%
  * Test Accuracy: 81.89%
  * Macro Precision: 86.99%
  * Weighted F1-Score: 81.39%
  * Average Inference Latency: 21.58 ms per image
